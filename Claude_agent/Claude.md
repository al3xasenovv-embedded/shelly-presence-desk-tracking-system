## Проектът в едно изречение

IoT desk presence tracking система, изградена върху Shelly BLU хардуер, Node-RED, PostgreSQL, FastAPI и React — учебен/пилотен проект за навлизане в full-stack IoT разработка.

## Технически stack

- **Node-RED** — device integration layer (MQTT обработка, toggle логика, session detection)
- **PostgreSQL** — единствен източник на истина за данните (desk_sessions, work_sessions)
- **Docker** — за инфраструктурни компоненти (в момента: Mosquitto; PostgreSQL остава native за сега)
- **FastAPI** — read-side API слой, чете от PostgreSQL, поднася готови данни
- **React** — frontend, консумира FastAPI endpoints
